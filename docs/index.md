# Hearth for WebOS

Hearth is a quiet, fast home screen for LG TVs. It shows a clock, the weather and your apps in one neat row.

- **New here?** Start with the [Beginners guide](BEGINNERS-GUIDE.md). It explains every word and every step, like a story.
- **Want to know what Hearth can do?** Read [Everything Hearth can do](customizing.md).
- **Want to change how it looks?** See [Look](features/look.md), [Widget](features/widget.md) and [Wallpaper](features/wallpaper.md), or make a [custom theme](theme/theme-guide.md).
- **Something is wrong?** Open [Troubleshooting](troubleshooting.md).
- **Does it work on my TV?** See the [Tested TVs](COMPATIBILITY.md), then [send your own report](https://github.com/rudra-avatar/Hearth/issues/new?template=compatibility.yml).
- **Source, downloads and questions:** [github.com/rudra-avatar/Hearth](https://github.com/rudra-avatar/Hearth).
